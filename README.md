# Logistics Studio

This is a premium marketing website for Logistics Studio built with Next.js, TypeScript, Tailwind CSS, and animated using GSAP and Three.js.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

3. Build the application for production:
```bash
npm run build
```

4. Start the production server:
```bash
npm start
```
